# Phase 0 规格：窗口响应矩阵

> 状态：规格定稿（用户已批准 1440×900 默认）
> 实施：Phase 2（Chimera Shell 与窗口系统）；本 Phase 只定规格

## 1. 窗口尺寸

| 项 | 值 | 说明 |
|---|---|---|
| 默认尺寸 | **1440×900** | 用户决策（2026-08-16），主流工作尺寸 |
| 设计基准 | 1440×900 | 设计稿画板同尺寸（1:1 对照） |
| 最小尺寸 | 960×640 | 低于此不保证布局完整 |
| 记忆窗口 | 启用（现有 `windowState` 已支持） | 用户调整后优先于默认值 |
| 全屏 | 支持（系统行为） | 全屏时应用 UI 约束同 1920 档 |
| Titlebar | 隐藏 + overlay（现有实现） | Windows/macOS 统一 |

**代码改动（Phase 2）**：`packages/desktop/src/main/windows.ts` 的 `defaultWidth: 1440, defaultHeight: 900`，并显式设置 `minWidth: 960, minHeight: 640`（确认 windowState 库透传）。

## 2. 响应矩阵

| 尺寸 | 适用 | Spine | Workspace Strip | Context Ribbon | 侧面板（文件树/审查/终端） | Composer |
|---|---|---|---|---|---|---|
| ≥1440×900 | 默认/大屏 | 图标+文字 | 完整 | 常驻极简条 | 可同开 2 个 | 完整配方 |
| 1280×800 | 笔记本 | 图标+文字 | 完整 | 常驻极简条 | 同开 1 个（按需切换） | 完整配方 |
| 960×640（最小） | 窄窗口 | 仅图标 | 折叠次要信息 | 折叠为小点/图标 | 同开 1 个，覆盖式 | 渐进展开（默认极简） |
| 全屏 1920+ | 全屏 | 同 1440 档 | 完整 | 常驻 | 可同开 3 个 | 完整配方 |

### 约束原则

1. **侧面板不得把 Composer 挤出视口**——任何尺寸下输入区始终可见、可聚焦。
2. Context Ribbon 三条降级路径：`极简条 → 小点 → 隐藏（Hover 显示）`。
3. 内容列（会话正文）在 1440 基准下 860px（现状），1280 时收窄、960 时占满可用宽度。
4. DPI：Windows 100% / 125% / 150% 三档验证；布局用逻辑像素（现有 Electron 默认），重点核对 125%/150% 下无裁切。

## 3. dev/release 一致性

- dev 与 release 使用同一组窗口约束（现有实现已共用 `createMainWindow`）
- 验收：同一尺寸/DPI 下 dev 与打包版布局一致

## 4. 验收清单

- [ ] 1440×900 无裁切，内容列与设计稿 1:1
- [ ] 960×640 主路径（新建→会话→输入→切换模型）可用
- [ ] 1280×800 侧面板同开不挤压 Composer
- [ ] Windows 125%/150% DPI 无裁切/错位
- [ ] 记忆窗口尺寸生效（调整后重启保持）
- [ ] 全屏进出无布局回归
